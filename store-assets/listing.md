# Chrome Web Store Listing Copy

## Name

Hypercalculator

## Summary

Visual calculator for graphs, geometry, vectors, complex numbers, and 3D math objects.

## Detailed Description

Hypercalculator is a visual calculator for learning and exploring math. Type an expression, press equals, and the calculator turns it into something you can inspect: a graph, a geometry object, a vector, a complex number, a ratio, or a 3D surface.

It includes a scientific keypad, keyboard input, history, radians/degrees, root solving, symbolic derivative and antiderivative views, axis labels, zoom controls, a 2D geometry composer, and 3D primitives such as spheres, cubes, cylinders, cones, planes, and 3D lines.

Use it as a side panel when you want a persistent calculator, or open the floating overlay when you want Hypercalculator on top of the page you are studying.

All computation runs locally in your browser. Hypercalculator does not collect, sell, transmit, or store personal data.

## Privacy Disclosure

Hypercalculator does not collect user data. It does not use analytics, accounts, tracking scripts, cookies, or remote API calls.

The extension requests `activeTab` so it can inject the floating overlay only after you explicitly invoke it. It does not request standing access to every site you visit.
